## 🎯 Sobre o Repositório

O objetivo deste espaço é manter um histórico estruturado e de fácil consulta de todo o aprendizado prático e teórico das aulas:

- Sintaxe essencial e estruturas de controle
- Funções avançadas, closures, callbacks e escopo
- Programação orientada a objetos (Prototypes, Classes, Factory/Constructor Functions)
- Manipulação de arrays e objetos (`map`, `filter`, `reduce`, `Object.defineProperty`)
- JavaScript assíncrono (Promises, `async/await`, Fetch API)
- TypeScript: tipagem estática, interfaces, generics e boas práticas

> 💡 **Nota:** Para manter a organização do perfil no GitHub, este repositório concentra apenas o código e exercícios das aulas. Os projetos práticos maiores e aplicações completas possuem repositórios dedicados próprios.

## 🛠️ Como Executar os Códigos

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado na máquina (versão LTS recomendada).

### Executando um exercício
Para rodar qualquer um dos arquivos JavaScript via terminal:

```bash
# Clone o repositório
git clone https://github.com/Davi-PF/curso-js-ts-aulas.git

# Acesse a pasta do projeto
cd curso-js-ts-aulas

# Execute a aula desejada (exemplo: aula 72)
node ./aula72/aula72.js
```
